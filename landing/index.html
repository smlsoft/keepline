💬 "สรุปลูกค้าที่เสี่ยงหายให้หน่อย"

→ AI ดึง list_customers + get_kpi ผ่าน MCP แล้วสรุปให้ว่าลูกค้ารายไหนไม่ทักมานาน ควรติดต่อใครก่อน

📊 "วิเคราะห์ยอดขายเดือนนี้เทียบกับเดือนก่อน"

→ AI ดึง get_analytics + list_payments ผ่าน MCP แล้ววิเคราะห์แนวโน้ม แนะนำกลยุทธ์เพิ่มยอด

📋 "เช็คงานภาษีเดือนนี้ที่ยังค้างอยู่"

→ AI ดึง list_tax_deadlines + list_tasks ผ่าน MCP แล้วสรุปงานที่ยังไม่เสร็จ deadline ใกล้ถึง

🔍 "หาแชทที่ลูกค้าพูดถึงสินค้า X"

→ AI ดึง search_messages ผ่าน MCP ค้นหาข้อความทั้งระบบ สรุปว่าลูกค้ากี่รายสนใจ ใครพร้อมซื้อ
